# Case #0210: The Unwritten Wish

An interactive, Death Note–inspired birthday experience for Raajiv.

A cinematic "investigation" that moves through clues, a secret-code puzzle, a
memory-ordering vault, and a Shinigami interrogation — before revealing that the
real target was never a person, but a wish.

## Run locally

Open `index.html` in any modern browser. All assets are local except the
Google Fonts and background music, which load over the internet.

## Hosting (GitHub Pages)

1. Push this folder to the repository.
2. In the repo: **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, Branch: **main** / root (`/`).
4. The site goes live at `https://<username>.github.io/Raajiv-Birthday/`.

## Files

- `index.html` — the full single-page experience (HTML/CSS/JS)
- `image 1.jpeg` — cinematic background
- `Death Note.jpeg` — Shinigami / character art
- `PIND.jpeg`, `AR_Concert.jpeg`, `Holi.jpeg` — memory-vault photos
